# AWS HTML Report Generator - Version 2.13.6

## Summary
Styled Lambda Functions and ECS Clusters headers to match VPC style (blue color, underline border, onclick toggle). Added comprehensive Load Balancers section with separate ALB and NLB subsections.

## What Changed

### Lambda & ECS Header Styling

**Before (v2.13.5):**
```
► Lambda Functions (31)  [plain black text, no border]
► ECS Clusters (2)       [plain black text, no border]
```

**After (v2.13.6):**
```
► Lambda Functions (31)  [blue text, blue underline border, matches VPC style]
► ECS Clusters (2)       [blue text, blue underline border, matches VPC style]
```

**Styling applied:**
- Color: `#667eea` (blue)
- Font size: 18px, weight: 600
- Border-bottom: 3px solid `#667eea`
- Cursor: pointer
- Uses onclick="toggleSection()" like VPCs

**Visual Consistency:**
Now matches `► VPC: vpc-name` headers exactly!

### Load Balancers Section Added

**New major section** displaying all load balancer data collected by verification script.

**Structure:**
```
▼ Load Balancers [h2 - main section]
  ► Application Load Balancers (1) [h4 - blue, underline, collapsible]
     [table with ALB details]
  
  ► Network Load Balancers (1) [h4 - blue, underline, collapsible]
     [table with NLB details]
```

**Table Columns:**
| Column | Content |
|--------|---------|
| Name | Load balancer name (code style) |
| Scheme | internet-facing (⚠️ yellow) / internal (🔵 blue) |
| VPC | VPC ID |
| AZs | Comma-separated availability zones |
| Listeners | Protocol:Port (e.g., HTTPS:443, TCP:5432) |
| Target Groups | Name (healthy/total) (e.g., chainlit-target-group (2/2 healthy)) |

**Example Output:**

**Application Load Balancers:**
| Name | Scheme | VPC | AZs | Listeners | Target Groups |
|------|--------|-----|-----|-----------|---------------|
| chainlit-alb | internal | vpc-076d8... | eu-west-1a, eu-west-1b | HTTPS:443 | chainlit-target-group (2/2 healthy)<br>ska-bcc-chainlit-target-group (2/2 healthy) |

**Network Load Balancers:**
| Name | Scheme | VPC | AZs | Listeners | Target Groups |
|------|--------|-----|-----|-----------|---------------|
| dtpl-insights-prep-rds-nlb | internal | vpc-076d8... | eu-west-1a, eu-west-1b, eu-west-1c | TCP:5432 | dtpl-insights-prep-rds-tg (1/1 healthy) |

**Features:**
- Separates ALBs and NLBs into collapsible subsections
- Shows target group health status (healthy/total)
- Color-codes scheme badges (warning for internet-facing)
- Multiple listeners shown on separate lines (using `<br>`)
- Multiple target groups shown on separate lines

## Data Source

Load balancer data comes from `Load Balancer Verification` section in verification output:
```python
{
  "title": "Load Balancer Verification",
  "checks": [
    {
      "LoadBalancerName": "chainlit-alb",
      "Type": "application",
      "Scheme": "internal",
      "VPC": "vpc-076d8154ea7d39807",
      "AvailabilityZones": ["eu-west-1a", "eu-west-1b"],
      "Listeners": [{"Protocol": "HTTPS", "Port": 443}],
      "TargetGroups": [{"Name": "...", "HealthyTargets": 2, "TotalTargets": 2}]
    }
  ]
}
```
