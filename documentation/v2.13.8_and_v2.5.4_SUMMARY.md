### ECS Services Table - Load Balancer vs Target Group

**The Problem:**
Previously showed target group name in "Load Balancer" column, which was misleading. The target group (e.g., `ska-bcc-chainlit-target-group`) is hosted on a load balancer (e.g., `chainlit-alb`), not the load balancer itself.

**Before (v2.13.7):**
| Service Name | Status | ... | Load Balancer |
|--------------|--------|-----|---------------|
| ska-bcc-chainlit-service | ACTIVE | ... | ska-bcc-chainlit-target-group:8000 |

**After (v2.13.8):**
| Service Name | Status | ... | Load Balancer | Target Group |
|--------------|--------|-----|---------------|--------------|
| ska-bcc-chainlit-service | ACTIVE | ... | chainlit-alb | ska-bcc-chainlit-target-group:8000 |

Now correctly shows:
- **Load Balancer column**: The actual ALB/NLB name (e.g., `chainlit-alb`)
- **Target Group column**: Target group name with port (e.g., `ska-bcc-chainlit-target-group:8000`)

**Column Widths (7 columns total):**
| Column | Width |
|--------|-------|
| Service Name | 25% (reduced from 28%) |
| Status | 10% |
| Desired Tasks | 10% |
| Running Tasks | 10% |
| Launch Type | 10% |
| Load Balancer | 15% ✅ NEW |
| Target Group | 20% (reduced from 32%) |

## aws_build_verification v2.5.4

### Load Balancer Name Lookup

**New Feature:** Verification script now looks up which load balancer hosts each target group.

**How it works:**
1. Builds a mapping of target group ARNs to load balancer names
2. For each ECS service, extracts target group ARN from service config
3. Looks up the load balancer name from the mapping
4. Adds `LoadBalancerName` field to ServiceDetails

**Example mapping:**
```python
{
  'arn:aws:elasticloadbalancing:...:targetgroup/ska-bcc-chainlit-target-group/...': 'chainlit-alb',
  'arn:aws:elasticloadbalancing:...:targetgroup/dtpl-insights-prep-rds-tg/...': 'dtpl-insights-prep-rds-nlb'
}
```

**ServiceDetails output:**
```python
{
  'ServiceName': 'ska-bcc-chainlit-service',
  'Status': 'ACTIVE',
  'DesiredCount': 2,
  'RunningCount': 2,
  'LaunchType': 'FARGATE',
  'LoadBalancers': [
    {
      'targetGroupArn': 'arn:aws:elasticloadbalancing:...',
      'containerPort': 8000
    }
  ],
  'LoadBalancerName': 'chainlit-alb'  # ✅ NEW
}
```

## Data Flow

```
ECS Service (raw data)
  └─ loadBalancers: [{ targetGroupArn: "arn:...:targetgroup/ska-bcc-chainlit-target-group/..." }]

Load Balancer Verification Data
  └─ chainlit-alb
      └─ TargetGroups: [{ Name: "ska-bcc-chainlit-target-group", ... }]

Verification Script (v2.5.4)
  1. Extract target group ARN from service
  2. Look up in load balancer data
  3. Find: ska-bcc-chainlit-target-group is on chainlit-alb
  4. Add LoadBalancerName: "chainlit-alb" to ServiceDetails

HTML Report (v2.13.8)
  Display:
  - Load Balancer: chainlit-alb
  - Target Group: ska-bcc-chainlit-target-group:8000
```
