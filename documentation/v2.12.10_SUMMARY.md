# AWS HTML Report Generator - Version 2.12.10

## Summary
Fixed Network ACLs display to add VPC ID and Owner ID columns for better clarity, matching AWS console layout.

## What Changed

### Added Columns to NACL Table

**New columns:**
1. **VPC ID** - Shows which VPC each NACL belongs to
2. **Owner ID** - Shows the AWS account that owns the NACL

**Updated table structure:**

| Column | Width | Content |
|--------|-------|---------|
| NACL ID | 18% | Clickable ID for full details |
| **VPC ID** | 15% | **NEW** - VPC this NACL belongs to |
| **Owner ID** | 12% | **NEW** - AWS Account Owner |
| Default | 8% | ✅ Yes / ❌ No |
| Inbound | 8% | Count of inbound rules |
| Outbound | 8% | Count of outbound rules |
| Assocs | 8% | Count of associations |
| Associated Subnets | 23% | Clickable subnet IDs |

### Column Width Optimization

Adjusted widths to accommodate new columns while keeping everything on one line:
- Reduced NACL ID: 25% → 18%
- Added VPC ID: 15%
- Added Owner ID: 12%
- Reduced Default: 10% → 8%
- Renamed and reduced Inbound Rules: 12% → 8% "Inbound"
- Renamed and reduced Outbound Rules: 12% → 8% "Outbound"
- Renamed and reduced Associations: 10% → 8% "Assocs"
- Reduced Associated Subnets: 31% → 23%

### Clarification on NACL Count

The count shown in the heading (e.g., "Network ACLs (1)") represents the number of NACLs **in that specific VPC**, not the total across all VPCs. This is correct behavior since:
- NACLs are VPC-specific resources
- Each VPC section shows only its own NACLs
- Multiple VPCs will each have their own "Network ACLs" section with their respective counts

**Example:**
- VPC 1 has 1 NACL → Shows "Network ACLs (1)"
- VPC 2 has 1 NACL → Shows "Network ACLs (1)"
- Total across report: 2 NACLs

This matches how VPC Endpoints and VPC Peering are displayed (per-VPC counts).

### Column Span Updates

Updated expandable detail rows to span all 8 columns (was 6):
- NACL details drill-down
- Subnet details drill-down

## Technical Details

### Data Source
- VPC ID: From `nacl.get('VpcId')`
- Owner ID: From `nacl.get('OwnerId')`

### Styling
- VPC ID shown in code style (monospace, gray background)
- Owner ID shown as plain text (account number)

## Note on NACL Counts

The heading shows per-VPC counts (e.g., "Network ACLs (1)"), which is correct since NACLs are VPC-specific. If you have 2 VPCs each with 1 NACL, you'll see two sections each showing "(1)". This matches the AWS console approach where NACLs are viewed per-VPC.
