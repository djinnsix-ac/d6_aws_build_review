# Version 2.9.0 - Security Group Network Visualization

## What's New

**Interactive D3.js network graph** showing security group connections, ports, and protocols.

## Features

### Visual Network Diagram
- **Nodes** = Security Groups (and Internet)
- **Edges** = Traffic rules between groups
- **Edge labels** = Protocols and ports
- **Color coding:**
  - 🔴 Red: From Internet (0.0.0.0/0)
  - 🟡 Yellow: Broad CIDR blocks
  - 🟢 Green: SG-to-SG connections

### Interactions
- **Drag nodes** to organize the layout
- **Click a node** to highlight only its connections
- **Hover edges** for full rule details (protocol, ports, CIDR)
- **Hover nodes** for SG details (ID, VPC, rule counts)
- **Reset view** button to clear filters
- **Show Internet-Exposed** button to focus on public-facing SGs

### How It Handles Many-to-Many
- Force-directed physics keeps nodes organized
- Click-to-filter cuts through complexity
- Hover tooltips show details without cluttering
- Draggable nodes let you untangle connections

## What You'll See

**Internet-exposed security group:**
- Large red node labeled "Internet"
- Red edges to SGs with 0.0.0.0/0 rules
- Those SGs appear light red

**SG-to-SG connections:**
- Green edges between security groups
- Protocol and ports labeled on hover

**Complex many-to-many:**
- Multiple edges fan out from application tier
- Click a node to focus on its connections only
- Other nodes fade to 20% opacity
