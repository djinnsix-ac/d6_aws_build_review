# AWS HTML Report Generator - Version 2.12.8

## Summary
Added comprehensive Network ACLs (NACLs) section with clickable subnet associations, detailed rule views, and uniform formatting matching other VPC sections.

## What Changed

### 1. New Network ACLs Section (h4 Level)
Added collapsible section after VPC Peering showing all Network ACLs:

**Summary Table Columns:**
| Column | Width | Content |
|--------|-------|---------|
| NACL ID | 25% | Clickable ID for full details |
| Default | 10% | ✅ Yes / ❌ No |
| Inbound Rules | 12% | Count of inbound rules |
| Outbound Rules | 12% | Count of outbound rules |
| Associations | 10% | Count of subnet associations |
| Associated Subnets | 31% | Clickable subnet IDs |

**Visual Indicators:**
- ✅ Yes - Default NACL
- ❌ No - Custom NACL

### 2. NACL Drill-Down Details
Click any NACL ID to see comprehensive information:

**Inbound Rules Table:**
- Rule Number (sorted)
- Action (ALLOW in green / DENY in red)
- Protocol (All, TCP, UDP, ICMP)
- Port Range (single port or range)
- Source CIDR

**Outbound Rules Table:**
- Rule Number (sorted)
- Action (ALLOW in green / DENY in red)
- Protocol (All, TCP, UDP, ICMP)
- Port Range (single port or range)
- Destination CIDR

**Additional Info:**
- VPC ID
- Default NACL indicator
- Complete tags

### 3. Clickable Subnet Associations
Subnet IDs in "Associated Subnets" column are clickable to show full subnet details:
- All subnet information (AZ, CIDR, state, available IPs, etc.)
- Auto-assign public IP setting
- IPv6 CIDR blocks
- Complete tags

### 4. Protocol Mapping
Translates AWS protocol numbers to readable names:
- `-1` → All
- `6` → TCP
- `17` → UDP
- `1` → ICMP

### 5. Rule Sorting
Rules displayed in order by rule number (lowest to highest) for easy scanning.

### 6. Uniform Text Sizing
All table rows use 12px font size for consistency with Route Tables section.

## Technical Details

### New Helper Function
`generate_nacl_details(nacl)` - Formats comprehensive NACL information:
- Basic configuration
- Sorted inbound rules with color-coded actions
- Sorted outbound rules with color-coded actions
- Protocol number to name mapping
- Port range formatting
- Complete tags

### Color Coding
- **ALLOW** actions: Green (#10b981)
- **DENY** actions: Red (#ef4444)

### Data Source
- Uses `NetworkACLs` from VPC data collected by `aws_build_review` script
- Each NACL includes entries (rules) and subnet associations

### Column Width Optimization
Widths optimized to fit all content on one line:
- NACL ID: 25% (full IDs visible)
- Default: 10% (emoji + text)
- Inbound/Outbound Rules: 12% each (counts)
- Associations: 10% (count)
- Associated Subnets: 31% (multiple clickable IDs with line breaks)

## Security Value

Network ACLs are a critical security layer showing:
- **Stateless filtering** at subnet level
- **Rule priority** via rule numbers
- **Default deny** behavior (rule 32767)
- **Custom rules** for traffic control
- **Subnet coverage** showing which subnets are protected

This complements Security Groups (instance level, stateful) with subnet level (stateless) controls.
