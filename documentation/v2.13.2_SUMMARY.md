# AWS HTML Report Generator - Version 2.13.2

## Summary
Fixed Lambda table column widths (Function Name now 40%), show VPC ID when Lambda is in VPC, and fixed ECS clusters not displaying by removing fields that don't exist in verification data.

## What Changed

### Lambda Table Improvements

**Column Widths:**
| Column | Width | Purpose |
|--------|-------|---------|
| Function Name | 40% | Much wider for long names ✅ |
| Runtime | 15% | Compact (python3.9, etc) |
| Memory (MB) | 12% | Compact numbers |
| Timeout (s) | 12% | Compact numbers |
| VPC | 21% | Shows VPC ID or ✗ |

**VPC Display:**
- Before: `✓` or `✗` only
- After: Shows actual VPC ID (e.g., `vpc-076d8154ea7d39807`) or `✗`
- VPC IDs displayed with `.code` class for consistency

**CSS Added:**
```css
.lambda-table {
    table-layout: fixed;
}
.lambda-table th:nth-child(1), .lambda-table td:nth-child(1) { width: 40%; }
.lambda-table th:nth-child(2), .lambda-table td:nth-child(2) { width: 15%; }
/* etc */
```

### ECS Display Fixed

**Problem:** ECS clusters weren't showing because code referenced fields that don't exist in verification data.

**Removed fields:**
- ❌ `ClusterArn` - not in verification output
- ❌ `PendingTasks` - not in verification output  
- ❌ `PendingCount` (services) - not in verification output

**ECS Cluster Table (after fix):**
| Property | Value |
|----------|-------|
| Status | ACTIVE |
| Registered Instances | 0 |
| Running Tasks | 8 |
| Active Services | 4 |

**ECS Services Table (after fix):**
| Service Name | Status | Desired | Running | Launch Type |
|--------------|--------|---------|---------|-------------|
| ska-chainlit-service | ACTIVE | 2 | 2 | FARGATE |
