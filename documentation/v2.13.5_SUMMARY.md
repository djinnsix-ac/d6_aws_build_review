# AWS HTML Report Generator - Version 2.13.5

## Summary
Added JavaScript to make h4.collapsible elements (Lambda Functions, ECS Clusters) actually collapsible with click handling. Adjusted ECS services table column widths: Service Name 28%, Load Balancer 32%.

## What Changed

### Collapsible JavaScript Added

**Problem:** Lambda Functions and ECS Clusters had `class="collapsible"` but no JavaScript to handle clicks.

**Solution:** Added JavaScript handler for `h4.collapsible` elements:
```javascript
document.querySelectorAll('h4.collapsible').forEach(h4 => {
    h4.style.cursor = 'pointer';
    
    const content = h4.nextElementSibling;
    if (content && content.classList.contains('collapsible-content')) {
        content.style.display = 'none';  // Start collapsed
        
        h4.addEventListener('click', function() {
            if (content.style.display === 'none') {
                content.style.display = 'block';
                h4.innerHTML = h4.innerHTML.replace('►', '▼');
            } else {
                content.style.display = 'none';
                h4.innerHTML = h4.innerHTML.replace('▼', '►');
            }
        });
    }
});
```

**Behavior:**
- Sections start collapsed (hidden)
- Click header to expand/collapse
- Arrow changes: ► (collapsed) ↔ ▼ (expanded)
- Cursor changes to pointer on hover
