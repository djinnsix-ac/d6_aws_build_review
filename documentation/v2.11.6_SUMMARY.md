# Version 2.11.6 Summary - Rule Numbering & Display Fixes

## Three Bugs Fixed ✅

### 1. Rule Numbering Continues Across IpPermissions
**Problem**: When a security group had 3 separate IpPermissions entries, they were numbered:
- Rule 1, Rule 1, Rule 2 ❌

**Fixed**: Now correctly numbered:
- Rule 1, Rule 2, Rule 3 ✅

**Why**: The `rule_counter` was resetting for each `IpPermissions` object. Now it persists across all rules in a security group.

### 2. Port Range 0-65535 Detected as "All Ports"
**Problem**: Port range `0-65535` was displayed as `0-65535` ❌

**Fixed**: Now displays as `All Ports (0-65535)` ✅

**Why**: This is effectively all TCP/UDP ports and should be highlighted as such, matching AWS console behavior.

### 3. Added IP Version and Type Fields
**New Fields**:
- **IP Version**: Shows `IPv4`, `IPv6`, or omitted for SG references
- **Type**: Shows common service names:
  - `HTTPS` for port 443
  - `HTTP` for port 80  
  - `SSH` for port 22
  - `All TCP` for 0-65535 TCP
  - Protocol name otherwise

**Why**: Matches AWS console display and makes rules easier to understand at a glance.

## Technical Changes

### `format_security_group_rule()` Function
**Changed**:
- Now accepts `start_counter` parameter (default: 1)
- Returns tuple: `(html_string, next_counter)`
- `next_counter` is the number to use for the next rule

**Port Detection**:
```python
if from_port == 0 and to_port == 65535:
    port_display = 'All Ports (0-65535)'
```

**Type Field Logic**:
```python
type_display = 'HTTPS' if from_port == 443 and to_port == 443 else \
              'HTTP' if from_port == 80 and to_port == 80 else \
              'SSH' if from_port == 22 and to_port == 22 else \
              'All TCP' if from_port == 0 and to_port == 65535 and protocol == '6' else \
              proto_display
```

**IP Version Display**:
- IPv4 ranges: Shows `IP Version: IPv4`
- IPv6 ranges: Shows `IP Version: IPv6`
- SG references: Omitted (not applicable)
- Prefix lists: Omitted (not applicable)

### Caller Updates
Both ingress and egress rule sections now:
```python
rule_counter = 1
for rule_idx, rule in enumerate(ingress_details):
    html_chunk, rule_counter = format_security_group_rule(rule, 'ingress', rule_counter)
    ingress_rules_html += html_chunk
```

This ensures the counter persists across all rules.
