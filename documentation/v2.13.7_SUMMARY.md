# AWS HTML Report Generator - Version 2.13.7

## Summary
Made ECS cluster names collapsible h5 headers (matching VPC Configuration style), adjusted load balancer table column widths for professional appearance, AZs display on separate lines, and target groups are now clickable to show details.

## What Changed

### ECS Cluster Names - Now Collapsible h5

**Before (v2.13.6):**
```
▼ ECS Clusters (2)
   Cluster: chainlit-ecs-cluster [plain h4, not collapsible]
   [cluster info and services shown]
```

**After (v2.13.7):**
```
▼ ECS Clusters (2)
   ► Cluster: chainlit-ecs-cluster [h5, collapsible, matches VPC subsections]
      [cluster info and services hidden until clicked]
```

**Styling:**
- Color: `#2c5aa0` (blue)
- Font size: 15px
- Cursor: pointer
- Uses onclick="toggleSection()" 
- **Matches exactly**: Configuration, Subnet Distribution, Route Tables under VPCs

### Load Balancer Table Improvements

#### Application Load Balancers (ALB)

**Column Widths:**
| Column | Width | Purpose |
|--------|-------|---------|
| Name | 15% | Compact for ALB names |
| Scheme | 10% | Badge only |
| VPC | 15% | VPC ID |
| AZs | 10% | Multiple lines |
| Listeners | 10% | Protocol:Port |
| Target Groups | 40% | ✅ **Emphasized - clickable details** |

**Changes:**
- Target Groups: 20% → 40% (+20%)
- AZs: Comma-separated → Separate lines (`<br>`)
- Target Groups: Now clickable with expandable details

#### Network Load Balancers (NLB)

**Column Widths:**
| Column | Width | Change |
|--------|-------|--------|
| Name | 25% | +10% (was 15%) ✅ |
| Scheme | 8% | -2% (was 10%) |
| VPC | 17% | +2% (was 15%) |
| AZs | 15% | +5% (was 10%) |
| Listeners | 10% | -5% (was 15%) ✅ |
| Target Groups | 25% | +5% (was 20%) ✅ |

**Changes:**
- Name: Wider for longer NLB names
- Scheme: Narrower (badge only)
- Listeners: Narrower (typically simple protocols)
- Target Groups: Wider
- AZs: Separate lines (`<br>`)
- Target Groups: Clickable with expandable details

### Clickable Target Groups

**Feature:** Click target group name to see details

**Display:**
```
chainlit-target-group (2/2 healthy)  ← Underlined, clickable
  [click to expand]
  Protocol: HTTP
  Port: 80
  Health Check: Enabled
```

**Details shown:**
- Protocol (HTTP, HTTPS, TCP, etc.)
- Port number
- Health Check status (Enabled/Disabled)

**Styling:**
- Underlined text cursor: pointer
- Details in gray box (#f5f5f5)
- Small font (11px) for details
- Toggles show/hide on click

### Availability Zones (AZs)

**Before:**
```
eu-west-1a, eu-west-1b, eu-west-1c
```

**After:**
```
eu-west-1a
eu-west-1b
eu-west-1c
```

Each AZ on its own line for better readability.

## JavaScript Added

```javascript
function toggleDetails(id) {
    const detailsDiv = document.getElementById(id);
    if (detailsDiv) {
        if (detailsDiv.style.display === 'none') {
            detailsDiv.style.display = 'block';
        } else {
            detailsDiv.style.display = 'none';
        }
    }
}
```
