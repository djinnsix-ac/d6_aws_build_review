# AWS HTML Report Generator - Version 2.12.6

## Summary
Major Route Tables improvements - uniform text sizing, optimized column widths, visual emojis for Yes/No, and clickable subnets with full drill-down details.

## What Changed

### 1. Uniform Text Size
All route table rows now have consistent 12px font size across all columns for better readability.

### 2. Optimized Column Widths
Adjusted column widths to prevent wrapping in "Associated With" column:

| Column | Width | Purpose |
|--------|-------|---------|
| Route Table ID | 25% | Full RT IDs |
| Routes | 8% | Compact count |
| IGW Route | 12% | Emoji + text |
| NAT Route | 12% | Emoji + text |
| Associations | 10% | Compact count |
| Associated With | 33% | Full details on one line |

### 3. Visual Emojis
Replaced text-only indicators with emojis for better visual scanning:
- **✅ Yes** - Route present (IGW/NAT)
- **❌ No** - Route not present

Old: `✓ Yes` / `✗ No`  
New: `✅ Yes` / `❌ No`

### 4. Clickable Subnets with Details
Subnet IDs in "Associated With" column are now **clickable** to show full subnet details:

**Information shown:**
- Subnet ID and VPC
- Availability Zone
- CIDR Block (IPv4)
- State (available/pending)
- Available IP Address Count
- Auto-assign Public IP setting
- IPv6 CIDR Blocks (if configured)
- Complete tags table

**Example:**
```
Associated With: Subnet: subnet-abc123... (clickable, green underline)

Click to see:
┌─────────────────────────────────────────┐
│ Subnet: subnet-abc123...                │
│ VPC: vpc-xyz789...                      │
│ Availability Zone: eu-west-1a           │
│ CIDR Block: 10.0.1.0/24                │
│ State: available                        │
│ Available IP Addresses: 251             │
│ Auto-assign Public IP: No               │
└─────────────────────────────────────────┘
```

### 5. New Helper Function
Added `generate_subnet_details(subnet)` to format comprehensive subnet information with:
- Basic subnet configuration
- IP addressing details (IPv4 and IPv6)
- State and attributes
- Complete tags
