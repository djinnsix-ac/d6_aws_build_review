# AWS HTML Report Generator - Version 2.12.11

## Summary
Major restructuring - VPC name now collapsible, Network ACLs moved to single consolidated section showing ALL NACLs across all VPCs, removed Assocs column, widened VPC ID column.

## What Changed

### 1. VPC Name Now Collapsible
VPC heading now matches other h4-level sections with expand/collapse functionality:

**Before:**
```
VPC: dtpl-insights-prep-vpc (vpc-076d8154ea7d39807)
├─ ► Configuration
├─ ► Subnet Distribution
├─ ► Route Tables
├─ ► VPC Endpoints (26)
└─ ► VPC Peering Connections (1)
```

**After:**
```
► VPC: dtpl-insights-prep-vpc (vpc-076d8154ea7d39807)
  ├─ ► Configuration
  ├─ ► Subnet Distribution
  ├─ ► Route Tables
  ├─ ► VPC Endpoints (26)
  └─ ► VPC Peering Connections (1)
```

All VPC content (Configuration, Subnets, Routes, Endpoints, Peering) now contained within collapsible VPC section.

### 2. Network ACLs Consolidated
**MAJOR CHANGE:** Network ACLs moved outside per-VPC sections to show ALL NACLs in one place:

**Before:**
- Under VPC 1: Network ACLs (1)
- Under VPC 2: Network ACLs (1)
- Total shown: 2 sections

**After:**
- Single section: **Network ACLs (2)** at VPC Architecture level
- Shows all NACLs from all VPCs in one table
- Total count now accurate

This matches AWS console behavior where you can view all NACLs across VPCs.

### 3. Removed Associations Column
**Removed:** "Assocs" column (redundant with subnet count)  
**Kept:** "Associated Subnets" column with full subnet IDs

### 4. Widened VPC ID Column
Adjusted column widths:

| Column | Old Width | New Width | Change |
|--------|-----------|-----------|--------|
| NACL ID | 18% | 18% | - |
| VPC ID | 15% | **20%** | +5% |
| Owner ID | 12% | 12% | - |
| Default | 8% | 8% | - |
| Inbound | 8% | 8% | - |
| Outbound | 8% | 8% | - |
| Assocs | 8% | **removed** | -8% |
| Associated Subnets | 23% | **26%** | +3% |

## Benefits

1. **Correct Count** - Now shows total NACLs: "Network ACLs (2)" not "(1) + (1)"
2. **Better Organization** - All NACLs in one place for easy comparison
3. **VPC Context** - VPC ID column shows which VPC each NACL belongs to
4. **Consistent Collapsing** - VPC name now collapses like other h4 sections
5. **Cleaner Table** - Removed redundant Assocs column
6. **More Space** - Wider VPC ID and Associated Subnets columns

## Technical Details

### Structural Changes
1. VPC content wrapped in collapsible div: `<div id="vpc-content-{vpc_id}">`
2. NACLs moved outside per-VPC loop
3. Aggregates all NACLs: `all_network_acls.extend(nacls)` from each VPC
4. Aggregates all subnets for subnet lookup
5. Single NACL section with total count

### Column Span Updates
Changed from `colspan="8"` to `colspan="7"` for detail rows (removed Assocs column).
