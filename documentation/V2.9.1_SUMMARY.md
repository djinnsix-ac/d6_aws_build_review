## The Bug I Delivered
Line 2447 in v2.9.0 had wrong data extraction:
```python
# BROKEN in v2.9.0
section['raw_data'] = collected_data.get('SecurityGroups', {})
# This returned empty dict {}
```

## The Fix in v2.9.1
```python
# FIXED in v2.9.1
sg_raw = collected_data.get('SecurityGroups', {}).get('SecurityGroups', [])
section['raw_data'] = {'SecurityGroups': sg_raw}
# This gets the actual array of security groups
```

## Why the Bug Happened
AWS data structure is nested:
```
CollectedData/
  └─ SecurityGroups/         ← First level (dict)
       └─ SecurityGroups/    ← Second level (array) ← Need THIS
```

v2.9.0 only accessed first level, got empty dict.
v2.9.1 accesses second level, gets actual data.
