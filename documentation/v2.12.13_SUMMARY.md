# AWS HTML Report Generator - Version 2.12.13

## Summary
Moved Network ACLs back under individual VPCs at h5 level (same as Route Tables) since NACLs are VPC-specific resources. Removed VPC ID and Owner ID columns since they're redundant when shown per-VPC.

## What Changed

### Network ACLs Back to Per-VPC Display

**Before (v2.12.11):**
```
VPC Architecture
├─ ► VPC: vpc-name-1
│   └─ (subsections)
├─ ► VPC: vpc-name-2
│   └─ (subsections)
└─ ► Network ACLs (2) [h4] ← Consolidated, cross-VPC
    ├─ NACL 1 (with VPC ID column)
    └─ NACL 2 (with VPC ID column)
```

**After (v2.12.13):**
```
VPC Architecture
├─ ► VPC: vpc-name-1 [h4]
│   ├─ ► Configuration [h5]
│   ├─ ► Subnet Distribution [h5]
│   ├─ ► Route Tables [h5]
│   ├─ ► VPC Endpoints [h5]
│   ├─ ► VPC Peering [h5]
│   └─ ► Network ACLs (1) [h5] ← Per-VPC
│       └─ Default NACL for this VPC
└─ ► VPC: vpc-name-2 [h4]
    └─ ► Network ACLs (1) [h5] ← Per-VPC
        └─ Default NACL for this VPC
```

### Simplified Table Columns

Removed redundant columns since NACLs now shown per-VPC:

| Column | Width | Purpose |
|--------|-------|---------|
| NACL ID | 22% | Clickable ID for full details |
| Default | 10% | ✅ Yes / ❌ No |
| Inbound | 10% | Count of inbound rules |
| Outbound | 10% | Count of outbound rules |
| Associated Subnets | 48% | Clickable subnet IDs (wider!) |

**Removed columns:**
- ~~VPC ID~~ (redundant - shown in VPC heading)
- ~~Owner ID~~ (redundant - same for all NACLs in VPC)

### Heading Level Change

Network ACLs now **h5** (blue, 15px) matching other VPC-specific sections:
- Same level as Configuration, Subnet Distribution, Route Tables
- NOT h4 (purple, 18px) like VPC name

## Rationale

Network ACLs are **VPC-specific** resources:
- Every VPC has exactly one default NACL
- Custom NACLs belong to a single VPC
- NACL rules apply at the subnet level within that VPC
- AWS console shows NACLs per-VPC

Just like:
- Route Tables (VPC-specific)
- Subnets (VPC-specific)
- VPC Endpoints (VPC-specific)

## Benefits

1. **Logical Grouping** - NACLs with their VPC's subnets and routes
2. **No Redundant Columns** - VPC ID and Owner ID obvious from context
3. **More Space** - Associated Subnets column now 48% (was 26%)
4. **Consistent Hierarchy** - All VPC-specific sections at h5 level
5. **Cleaner Display** - Simpler table without cross-VPC information

## Technical Details

### Column Span Updates
Changed from `colspan="7"` to `colspan="5"` for detail rows (removed VPC ID and Owner ID columns).

### Styling
- h5 level: 15px, blue (#2c5aa0), no border-bottom
- Matches Route Tables, Subnet Distribution, Configuration, VPC Endpoints, VPC Peering

### Data Source
- NACLs from `raw_vpc.get('NetworkACLs', [])`
- Subnets from `raw_vpc.get('Subnets', [])` for same VPC

## Files Modified
- `generate_html_report-v2.12.13.py` - Moved NACLs back under VPCs at h5 level
