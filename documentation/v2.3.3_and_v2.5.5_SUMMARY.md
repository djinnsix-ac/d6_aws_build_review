# AWS Security Assessment Tools - Database Enhancements

## Overview
Added OpenSearch collection and significantly enhanced RDS details across all three scripts.

---

## aws_build_review v2.3.3

### New: OpenSearch Collection

**New method:** `get_opensearch_configuration()`

**Collects:**
- Domain names and IDs
- Engine version (OpenSearch/Elasticsearch version)
- Cluster configuration (instance type, count, dedicated master)
- VPC configuration (VPC ID, subnets, security groups, AZs)
- Endpoint information
- Encryption settings (at rest, node-to-node)
- Access policies
- Cognito authentication options
- Domain config details
- Tags

**Usage:**
```bash
python aws_build_review-v2.3.3.py --profile your-profile --region eu-west-1
```

Will now collect OpenSearch domains in addition to all other services.

---

## aws_build_verification v2.5.5

### Enhanced RDS Details

**Before (v2.5.4):** Basic info only
- Identifier, engine, version, instance class
- Storage type, allocated storage
- Multi-AZ, encryption, backup retention
- VPC, security groups

**After (v2.5.5):** Comprehensive details
- **All previous fields** PLUS:
- DBName (database name)
- Endpoint address and port
- Availability zone
- Max allocated storage, IOPS, throughput
- KMS key ID
- Backup/maintenance windows
- Latest restorable time
- Deletion protection
- IAM database authentication
- Performance Insights status
- Monitoring interval
- Auto minor version upgrade
- Subnet group name and subnet IDs

### New: OpenSearch Verification

**Collects:**
- Domain name, ID, ARN
- Engine version
- Endpoint URL
- Status flags (created, deleted, processing, upgrading)
- Instance type and count
- Dedicated master enabled
- Zone awareness
- VPC configuration (VPC ID, subnets, security groups, AZs)
- Encryption at rest
- Node-to-node encryption
- Domain endpoint options
- Access policies
- Cognito authentication
