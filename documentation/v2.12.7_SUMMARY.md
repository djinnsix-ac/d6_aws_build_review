## Additional VPC Data Available

During review, identified that we're collecting but **not currently displaying**:

### Network ACLs (NACLs)
- Collected in data: ✅ Yes (`NetworkACLs` in VPC data)
- Currently displayed: ❌ No
- Potential value: High (important security layer)

**Data available:**
- NACL ID and VPC
- Inbound/Outbound rules
- Rule numbers and priorities
- Allow/Deny actions
- Protocol, port ranges, CIDR blocks
- Subnet associations
- Default NACL indicator
- Tags

**Recommendation:** Add Network ACLs section in future version as h4-level collapsible section, similar to VPC Endpoints and Peering.
