# AWS HTML Report Generator - Version 2.12.9

## Summary
Standardized font sizes across all tables in the report - body text now uniformly 12px, headers uniformly 14px.

## What Changed

### Global Table Font Standardization

**Before:**
- Table body text: Varied (some 12px, some default ~16px)
- Table headers: Varied (some explicit sizes, some default)
- Inconsistent visual appearance across sections

**After:**
- **All table body text: 12px** (set in global `table` CSS)
- **All table headers: 14px** (set in global `th` CSS)
- Consistent visual appearance across entire report

### CSS Changes

```css
table {
    font-size: 12px;  /* Standardize all table body text to 12px */
}

th {
    font-size: 14px;  /* Standardize all table headers to 14px */
}
```

### Sections Affected

All tables throughout the report now have consistent sizing:

1. **Security Groups** - Main table and expanded rules
2. **VPC Configuration** - Configuration tables
3. **Route Tables** - Summary and details
4. **VPC Endpoints** - Summary table
5. **VPC Peering** - Summary table
6. **Network ACLs** - Summary table
7. **SageMaker** - Model endpoints and configurations
8. **Bedrock** - Model configurations
9. **CIS Benchmarks** - Compliance tables
10. **All other sections** - Uniform formatting

### Removed Inline Styles

Removed redundant inline `font-size: 12px` from:
- Route Tables rows
- Network ACLs rows

These now inherit from global CSS.

### Preserved Inline Styles

Kept explicit font-size in:
- NACL detail drill-down tables (nested tables within details)
- Other nested/special tables that need specific sizing

## Visual Consistency

**Headers (14px):**
- Large enough to be clearly headers
- Not overwhelming
- Good contrast with body text

**Body Text (12px):**
- Compact for information density
- Still easily readable
- Matches NACL rules tables (the reference standard)
- Consistent across all sections

## Benefits

1. **Professional Appearance** - Uniform sizing throughout
2. **Better Readability** - Appropriate size for data-dense tables
3. **Easier Maintenance** - Single source of truth in CSS
4. **Consistent UX** - Same experience across all sections

## Technical Details

### CSS Specificity
- Global styles in `<style>` block apply to all tables
- Inline styles only used where absolutely necessary (nested tables)
- Inheritance ensures consistency

### Font Sizes Used
- 12px body text: Good balance of density and readability
- 14px headers: Clear differentiation without being too large
- Same sizes used in NACL drill-down tables (the reference)
