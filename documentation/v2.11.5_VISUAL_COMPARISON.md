## How Service Names are Extracted

The script processes prefix list descriptions from your AWS security group rules:

**Input from AWS**: `"DynamoDB Gateway Egress"`
1. Remove region prefix: `"DynamoDB Gateway Egress"` (no prefix in this case)
2. Remove "Gateway Egress/Ingress": `"DynamoDB"`
3. Add "Endpoint": `"DynamoDB Endpoint"`

**Input from AWS**: `"com.amazonaws.eu-west-1.s3"`
1. Remove region prefix: `"s3"`
2. Already clean
3. Add "Endpoint": `"s3 Endpoint"`

**Fallback**: If no description available, shows prefix list ID (pl-xxxxx)
