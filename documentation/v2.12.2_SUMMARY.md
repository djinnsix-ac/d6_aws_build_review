# AWS HTML Report Generator - Version 2.12.2

## Summary
Enhanced VPC Architecture section with collapsible sections, clickable resource details, and better association visibility.

## What Changed

### 1. Collapsible Sections
**Subnet Distribution** and **Route Tables** sections now collapsible:
- Click section heading to expand/collapse
- Icons (â–¼/â–¶) indicate current state
- Reduces scrolling for large VPCs
- Content starts expanded by default

### 2. Clickable Internet Gateway Details
- IGW ID in Configuration table is now **clickable**
- Click to see full drill-down with:
  - VPC attachments and state
  - Owner ID
  - Complete tags table
- Details appear in expandable row below

### 3. Clickable Route Table Details  
- Route Table IDs in Route Tables section are now **clickable**
- Click to see full drill-down with:
  - Complete routes table (destination, target, status, origin)
  - Associations table (ID, associated resource, main status)
  - Complete tags
- Details appear in expandable row below

### 4. Route Table Associations Column
- New **"Associated With"** column shows what each route table is associated with:
  - "Main" for main route table
  - "Subnet: subnet-xxx" for subnet associations
  - "Gateway: igw-xxx" for gateway associations
  - "None" if no associations
- Multiple associations shown on separate lines

### 5. JavaScript Enhancement
- Added `toggleSection()` function for collapsible sections
- Icon rotation (â–¼ â†' â–¶) when toggling
- Consistent behavior with other expandable elements

## Technical Details

### New Helper Functions
1. **`generate_igw_details(igw)`** - Formats Internet Gateway drill-down
2. **`generate_route_table_details(rt)`** - Formats Route Table drill-down with routes and associations
3. **`toggleSection(id)`** - JavaScript function for collapsible sections

### Data Requirements
- Internet Gateway: Uses `raw_vpc['InternetGateways']` from collected data
- Route Tables: Uses `raw_vpc['RouteTables']` with full associations data
- Associations: Extracts `SubnetId`, `GatewayId`, and `Main` flag
