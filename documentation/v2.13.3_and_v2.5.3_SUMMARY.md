# AWS Security Assessment Tools - Version Updates

## generate_html_report v2.13.3

### Summary
Lambda and ECS sections now collapsible h5 headers, VPC display uses ✅/❌, ECS services table shows load balancer info with 40% service name width, clarified task counts.

### What Changed

#### Lambda Functions Section
- **Collapsible h5**: `► Lambda Functions (11)`
- **VPC Display**: 
  - ✅ `vpc-076d8154ea7d39807` (when in VPC)
  - ❌ (when not in VPC)
- Matches other collapsible sections in the report

#### ECS Clusters Section
- **Collapsible h5**: `► ECS Clusters (2)`
- **Services Table** with updated columns:

| Column | Width | Purpose |
|--------|-------|---------|
| Service Name | 40% | Long service names fit ✅ |
| Status | 10% | ACTIVE badge |
| Desired Tasks | 10% | Number of tasks desired |
| Running Tasks | 10% | Number of tasks running |
| Launch Type | 10% | FARGATE/EC2 |
| Load Balancer | 20% | Target group:port |

**Column Name Clarification:**
- Changed "Desired" → "Desired Tasks" (clear it's task count)
- Changed "Running" → "Running Tasks" (clear it's task count)

**Load Balancer Column:**
Shows target group and container port from AWS console:
- Example: `ska-bcc-chainlit-target-group:8000`
- Shows `—` if no load balancer attached

## aws_build_verification v2.5.3

### Summary
Added `LoadBalancers` field to ECS ServiceDetails so the HTML report can display target group and port information.

### What Changed

**ServiceDetails now includes:**
```python
'ServiceDetails': [
    {
        'ServiceName': 'ska-bcc-chainlit-service',
        'Status': 'ACTIVE',
        'DesiredCount': 2,
        'RunningCount': 2,
        'LaunchType': 'FARGATE',
        'LoadBalancers': [  # ✅ NEW
            {
                'targetGroupArn': 'arn:aws:elasticloadbalancing:...',
                'containerName': 'dtpl-insights-prep-ska-bcc-chainlit',
                'containerPort': 8000
            }
        ]
    }
]
```

**Data Source:**
Passes through `loadBalancers` array from raw ECS service data collected by aws_build_review script.

## Deployment Notes

**Both scripts must be updated together** because:
- Verification v2.5.3 adds LoadBalancers to ServiceDetails
- HTML report v2.13.3 expects LoadBalancers in ServiceDetails

If you only update the HTML report without updating verification, the Load Balancer column will show `—` for all services (no data available).
