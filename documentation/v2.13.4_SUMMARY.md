# AWS HTML Report Generator - Version 2.13.4

## Summary
Fixed Lambda Functions and ECS Clusters to use h4 headers (matching VPC style), and improved load balancer field extraction to handle both camelCase and PascalCase.

## What Changed

### Header Level Fix
**Before (v2.13.3):**
- Lambda Functions: h5 (smaller, blue)
- ECS Clusters: h5 (smaller, blue)

**After (v2.13.4):**
- Lambda Functions: h4 (matches VPC size/style) ✅
- ECS Clusters: h4 (matches VPC size/style) ✅

Both now match the `► VPC: vpc-name` header style in size and appearance.

### Load Balancer Field Extraction Improvement

**Problem:** Load balancer info wasn't showing because the code only checked PascalCase field names.

**Solution:** Now checks both naming conventions:
```python
# Try both field name variations
load_balancers = service.get('LoadBalancers', service.get('loadBalancers', []))
if load_balancers and len(load_balancers) > 0:
    lb = load_balancers[0]
    tg_arn = lb.get('targetGroupArn', lb.get('TargetGroupArn', ''))
    container_port = lb.get('containerPort', lb.get('ContainerPort', ''))
```

### Important Note on Load Balancers

**The load balancer column will only show data if you:**
1. Re-run verification with aws_build_verification-v2.5.3.py (or later)
2. This adds the LoadBalancers field to ServiceDetails
3. Then generate HTML report with this version

**If using old verification output (v2.5.2 or earlier):**
- Load Balancer column will show `—` for all services
- This is expected - the data isn't in the verification file
- Solution: Re-run verification with v2.5.3
